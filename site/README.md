# OneLauncher 官网部署文件

入口 `index.html`。文档入口 `docs/index.html`。整体保留 `assets/` 与 `docs/` 后上传任意静态托管即可，可以部署到域名根目录或子路径。

所有 JavaScript、GSAP 与图片都随网站本地提供，没有数据库、后端 API、第三方 CDN 或统计服务。下载按钮打开官方 GitHub Releases，不会在后台安装程序。

编辑和重建请使用单独的源码包；不要手改生成文档。原始素材使用条件和依赖许可见 `THIRD_PARTY_NOTICES.md`。源码核对日期 2026-11-17，提交 `507e3b7`，实际 Release 可早于本文源码。
